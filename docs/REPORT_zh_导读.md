## 一、术语表（按主题分组）

### A. 求解器与搜索

- **SAT（可满足性问题）**：给出一大堆"或"命题组成的条件，问能否给每个变量安排
  真假使所有条件同时成立。它是第一个被证明 NP 完全的问题。
  *本项目里*：我们用的"物理世界"就是 SAT 实例。
- **CDCL（冲突驱动子句学习）**：现代 SAT 求解器的标准算法。像侦探排案：猜一种
  变量赋值 → 撞出矛盾 → 把"这次为什么撞车"总结成新条目（学习子句）记下来 → 换
  方向重来。*本项目里*：我们研究的难度就是"CDCL 撞多少次车"。
- **冲突数（conflicts）**：CDCL 撞车的次数。同一台机器上它是秒表时间的高度相关
  替代品，但**跨机器可比**（秒表受 CPU 快慢影响）。*本项目里*：难度的主读数，
  全部结论建立在这上面。
- **传播（propagation）**：某些变量定了之后，大量其他变量的值被"顺便确定"——
  像多米诺。*本项目里*：大 r 实例曾出现"冲突很少但传播海啸"，是墙钟护栏存在的
  理由（AMEND-2）。
- **VSIDS / LRB**：两种著名的分支启发式——决定"下一个猜哪个变量"的打分规则。
  *本项目里*：Zulkoski 证明它们分支时"贴着社区走"（Gini≈0.5 vs 随机 0.16），
  这是 CDCL 行为具有局部性的证据。
- **重启（restarts）**：排案排到一半推倒重来的策略。*本项目里*：实验证明它对
  搜索局部性影响不大。
- **probSAT**：局部搜索类求解器（不推理，随机翻变量直到满足）。
  *本项目里*：已编译备用，作为"另一族算法"的对照。

### B. 图与结构

- **VIG（变量交互图）**：把每个子句（条件）里共同出现的变量两两连边得到的图。
  *本项目里*：实例"结构"的载体，社区、树宽都在这张图上算。
- **社区结构 / 模ularity（modularity）**：图分成几个内部热闹、彼此冷清的小圈子
  的程度；模ularity 是它的打分（0~1，越高越"圈子化"）。严格地说：模ularity =
  圈内实际边数与随机图期望边数之差的归一化和。
- **树宽（treewidth）**：图"有多接近一棵树"的指标，像"地图需要几种颜色才能保证
  相邻国家不同色"的最少颜色数减一（严格地说：树分解中最大袋子的容量减一）。
  *本项目里*：E1 证明它单独不制造难度——结构≠难度的关键证据。
- **退化度（degeneracy）**：图里"最粘人的顶点"有多少邻居，树宽的廉价下界近似。
- **谱隙（spectral gap）**：图拉普拉斯矩阵两大特征值之差，反映图的" connectivity
  断层"。*本项目里*：结构指标阶梯的一员。
- **度分布（degree distribution）**：每个变量出现在多少子句里的分布。
  *本项目里*：关键的受控量——度保持交换（E3b）把它钉死到逐字面程度。
- **幂律（power law）**：少数变量出现极多、大多数出现极少的"长尾"分布，
  工业实例的典型特征。

### C. 局部性与生成器（本项目自造术语）

- **局部性半径 r**：**本项目的核心旋钮**。生成子句时，只在二维环面上以某点为
  圆心、半径 r 的范围内抽变量。r 小 = 变量只和邻居互动；r 大 = 互动范围铺开。
- **geo_random**：我们主难度载体家族——非种植的几何随机 3-SAT（上述生成器的
  planted=False 模式）。它继承了 Bläsius 等人的几何体制。
- **种植实例（planted）**：先造一个满足解 σ，再围绕它造子句。*本项目里*：R1/R2
  发现种植实例对 CDCL 太简单，降级为稳健性臂。
- **σ-满足模式 / 冗余度**：围绕 σ 造子句的极性样式——先对 σ 满足的位置均匀抽一个
  基数 1..k，再抽该基数的子集（并非 7 种非空子集等概）。冗余度（每子句平均被 σ
  满足的字面数）实测均值 ≈2.14–2.23，r-不变。*本项目里*：把"内容分布"钉死的手段
  ——排除一个混淆。
- **度保持交换（E3b）**：把两个子句里的变量偷偷互换、但让每个字面的出现次数
  **一个不多一个不少**的洗牌术。效果：空间局部性被摧毁，而度序列纹丝不动。
  *本项目里*：结构摧毁干预——因果检验的"手术刀"。
- **2×2 析因**：拓扑{保持,破坏} × 内容{原始,重采样}的四格对照设计。
  （内容臂的操作化张力见 AMEND-3。）

### D. 相变与复杂度

- **相变 / 阈值 α_c**：固定变量数下，子句密度 α 从小到大，实例从"几乎全可满足"
  跳到"几乎全不可满足"的临界密度。严格地说：SAT 率=0.5 的插值交叉点（n=400
  的操作阈值，非热力学极限值 4.267）。*本项目里*：S0 全程在测的东西。
- **宽度屏障（width barrier）**：消解证明的"宽度"超过 √(n log n) 量级时，最短
  证明长度必然爆炸（Ben-Sasson–Wigderson）。*本项目里*：解释"为什么小 r 易、
  大 r 难"的理论标尺之一。
- **树宽→宽度→CDCL 链**：低树宽 ⇒ 存在窄证明 ⇒ 存在短证明 ⇒ 带重启 CDCL
  多项式找到。*本项目里*：E1 平坦结果的定理级解释。
- **OGP（重叠间隙性质）**：高维随机解空间里"解与解之间不够相似"的障碍，
  预示局部算法失效。*本项目里*：大 r 体制的理论背景（只做体制划分，不做保证）。
- **P vs NP**：本文不攻击它。我们的猜想来自对它的通俗讨论，但结论严格限于
  "CDCL + n=400 + 直接 CNF 编码"。

### E. 统计

- **删失（censoring）**：跑到预算上限还没出结果的实验——我们知道它"至少这么难"，
  但不知道精确难度。像"马拉松没跑完的选手，只知道他跑了 30 公里以上"。
  *本项目里*：冲突预算截断（精确）与 300s 墙钟（防海啸）两种。
- **Tobit 回归**：专门处理删失数据的回归——把"至少这么难"当截断信息用，而不是
  扔掉。
- **Kaplan–Meier 曲线**：生存分析的经典图，画"实例活了多久还没被解出"。
- **重复测量 ANOVA**：同一批种子在不同 r 下反复测难度（配对设计），方差分析
  检验 r 是否真的造成差异。partial η² 是效应量（差异占多大比例）。
- **Jonckheere–Terpstra（JT）**：检验"难度随 r 单调上升/下降"的趋势检验，
  蒙特卡洛置换算 p 值。
- **配对 Wilcoxon**：E3b 的主检验——同种子原始 vs 洗牌的成对比较。
- **因果中介（ACME）**：Imai 框架——r 的效果有多少是"通过结构指标"传导的。
  自助法（bootstrap）给置信区间。
- **BH-FDR**：多重检验校正——同时做很多检验时控制"假发现率"。
- **预注册**：跑主实验前把假设和判定标准冻结公开，防止"事后挑好看的结果"。
  *本项目里*：HYPOTHESES.md v1.0 + AMEND-1/2/3 修订链 + PRESPEC_AUDIT.md 审计。

## 二、常见问题（FAQ）

1. **为什么用冲突数不用秒表？** 秒表依赖 CPU 快慢和机器负载；冲突数是求解器内部
   计数，跨机器可比。秒表作为同机参考保留。
2. **n=400 是不是太小？** 是的，这是主要局限（预注册明写）。但干预设计的好处恰是
   在小 n 上也能 cleanly 测因果方向；规模扩展在路线图 E7。
3. **300 秒砍断会不会砍掉真相？** 会引入偏差——但方向已知（偏 UNSAT 侧 → α_c 被
   高估 → 对我们的假设反保守=夸大梯度），并且用 10⁸ 预算的 spot-check 定界
   （AMEND-2）。这是"诚实面对偏差"而非"假装没有"。
4. **为什么大 r 反而测不到阈值？** 因为中等密度的实例难度塌缩到测量范围之外
   （314/720 行墙钟截断集中在大 r）。这本身是结果：局部性改变的是"难度的结构"，
   不只是难度数值。
5. **树宽不是数学上的"好结构"吗，为什么 E1 里它不制造难度？** 树宽低⇒存在短证明
   ⇒CDCL 能找到——所以低树宽**保证容易**；但反过来高树宽**不保证难**。
   E1 显示"树宽单独"这个方向的因果力是零。易解性是单向保险，不是双向开关。
6. **如果结果支持哲学猜想，说明什么？** 说明"局部性因果地影响 CDCL 难度"在
   受控条件下成立——注意限于 CDCL、n=400、直接 CNF。对物理世界的"因果局部性"
   只是类比性的提示，不是证明。
7. **如果不支持呢？** 负结果同样是成果：预注册里写明了"密度主导"的量化触发条件，
   触发后我们如实报告，并把研究重心转成预测器叙事（E5）。负结果的价值在于它
   封死了一条流行直觉，省下别人的时间。
8. **这离证明 P=NP 有多远？** 隔着一整个太平洋。P vs NP 是关于*所有*算法的；
   我们研究的是一类算法（CDCL）在一族实例（几何随机）上的行为。连边都算不上，
   但它是普通人能摸到的最近的海岸线。
9. **为什么不让 ChatGPT 直接解 SAT？** 语言模型不是 SAT 求解器；我们的 E6 只用
   小模型做"分支排序建议"的探索性实验（H3），砍线已预注册（无信号即砍）。
10. **删失率和"测不到"有什么区别？** 删失=预算内没出判定（信息部分保留）；测不到
    =某个 r 的所有格都删失（阈值不可识别）。S0 里 r≥0.3 属于后者，所以用粗测值
    +低置信标记。
11. **为什么 σ-模式采样？** 一个 3-子句在 σ 下被满足的字面位置有 7 种非空组合，
    但实现并非以其等概抽样，而是先均匀抽基数 1..k、再抽该基数的子集；实测冗余度
    ≈2.14–2.23，跨 r 不变——内容分布被构造性钉死，不再依赖运气。
12. **度保持交换为什么是"手术刀"？** 它只动"谁和谁在空间上相邻"，不动"每个字面
    出现几次"。难度的任何变化都只能归因于前者——这就是因果推断里的"其他条件
    全部相同"。
13. **预注册被修改过吗？** 有三次，全部编号留痕（AMEND-1/2/3），理由公开，原文
    不可改写。修改是为了让实验可行或修正已发现的偏差，不是为了让结果好看——
    AMEND-2 修正的偏差方向恰恰对我们自己的假设不利。
14. **59 个 E4 真实实例够吗？** 不够 200–500 的目标，是网络受限下的替代源；
    只用于"落位"（我们的实例谱在真实谱系的哪里），不用于训练。缺口已声明。
15. **代码和数据可信吗？** 全部脚本可一键重跑，实例由 (家族,参数,种子) 决定性
    生成，结果库逐行落盘并进 git 版本控制；预注册-实现一致性逐条审计
    （PRESPEC_AUDIT.md）。

## 四、十句话总结（主结果版）

1. 我们把"因果局部性⇒问题好解"的哲学猜想变成了一台可拧旋钮的实验机器。
2. 旋钮是局部性半径 r：变量只在环面上半径 r 的范围内互相纠缠。
3. 读数是冲突数：现代求解器撞车的次数，跨机器可比。
4. 分界线随 r 移动：从低于 2.5 升到约 4.4——**局部性移动可满足/不可满足的分界线本身**。
5. 剂量-响应：钉死密度差后，r 从 0.06 到 0.22，难度跨 **3.4 个数量级**
   （28 次 → 7.2 万次撞车）；计入删失下界则 ≥4.5 个数量级。p<0.001。
6. 手术刀落下：只摧毁空间纠缠、保留度分布，难度立涨 16–68 倍，
   53 对实例的可满足性被翻转——**局部性是因果通道本身**。
7. 树宽单独不制造难度——起作用的是局部几何，不是全局拓扑的单一概括。
8. 中介成立：r 的效应约九成经由社区/谱结构的重组传导（置信区间不含 0）。
9. 这不是 P=NP 的进展；这是一类算法、一族实例上的一次干净测量。
10. 全程预注册、偏差实测定界、代码数据公开——你可以不同意我们，但你可以复现我们。
