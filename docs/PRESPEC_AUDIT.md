## 六A、功效分析补记（冻结"主要终点"节的承诺项）

配对设计 n=30 种子、双侧 α=0.05、power=0.80 ⇒ 可检测配对效应量 dz ≥ 0.52
（成对 t 检验正态近似；对应 RM-ANOVA 单因素在小 r 段的功效更优）。
换算到我们的主读数：dz=0.52 ≈ 相邻 r 水平间 log10 冲突数均值差 0.52×SD；
pilot R3b 的跨 r 端点 SD≈0.4–0.6（log10 尺度），即**可检测约 0.2–0.3 个
数量级的相邻格差**，而 R3b 实测端点差 >2 个数量级 ⇒ 功效充足（>0.99）。
若 E3a 实际 SD 因删失混合而膨胀，以实测 SD 复算并在报告 §6 报告实际功效。

## 八、分析阶段实现记录（E3a 完成后追加，2026-09-10）

1. **删失导致的非平衡**：冻结文本规定 RM-ANOVA 主检验；544/1980 删失使设计
   非平衡（AnovaRM 拒算）。处置：完全种子子集（全部 r 水平均 resolved 的种子，
   Δ 聚合后 n=28）进 RM-ANOVA——配对结构保持；JT 趋势用全部 resolved 行
   （统计功效优先）。敏感性：JT 双口径（clean / 删失按预算上限 6.0 计入），
   两者 p 同为 1e-4。
2. **全 Δ 合并的聚合**：同种子每 r 有 3 个 Δ 观测，违反"每 subject 每格单观测"
   ⇒ 按 (seed, r) 对 Δ 取均值后进 ANOVA。逐 Δ 分解另行报告（h2_by_delta_solver）。
3. **Tobit 收敛不良**（loglik=nan，删失混合下 Hessian 不可逆）：如实报告；
   删失敏感性由双口径 JT + KM 承担，结论一致。冻结文本要求 Tobit 为主——
   实际以非参数口径为主、Tobit 报告失败，此偏差如实声明。
   【2026-09-19 订正】本条描述的是 2026-09-17 修正前的实现：墙钟截断行携带 NaN
   进入似然而导致全量拟合不收敛。2026-09-17 起分析脚本按 AMEND-2 语义排除墙钟行，
   全量拟合收敛良好（loglik=−1721.7、σ=2.13，r 与 Δ 系数 p≈1e-194 与 1e-69），
   与主口径（双口径 JT + KM）结论一致。冻结协议"Tobit 为主"的偏离维持记录不变，
   但其"拟合不收敛"的理由自本注起由上述收敛结果取代（正文记载见 REPORT.md §8 与
   REPORT_zh.md §8）。
4. **η² 计算口径**：partial η² = F·df1/(F·df1+df2)（within 因子标准换算），
   在 RM-ANOVA 完全种子子集上计算。
5. **AMEND-2 spot-check 结果**（32 作业，10⁸/480s，4 新鲜种子 16–19）：
   r=0.3 在 α_c−0.2 处出现 2 SAT / 2 墙钟 ⇒ α_c(0.3) 高估实锤，偏差 ∈
   [−0.2, 0] 密度单位；r≥0.5 时 ±0.2 探针无法夹逼阈值——α_c+0.2 侧 12/12
   全部判定 UNSAT、α_c−0.2 侧 12/12 超时（10⁸/480s）⇒
   可测量性边界稳健。H2 主结论不受影响（Δ 匹配设计）。

   全部在出数前修复，不影响结果。

   "12:10" 晚于冻结提交 d046cd1（12:00:43）10 分钟——冻结链提交时间为准，
