## 一、定理链（从树宽到 CDCL 运行时间）
### 1. 消解宽度刻画（Atserias–Dalmau）
反驳宽度 w(F ⊢ ⊥) = 最小 k 使得存在宽度 k 的消解反驳空子句。AD 用"连接性/存在游戏"
给出组合刻画：宽度 ≤ w 的反驳存在 ⟺ 某个以 k 为参数的游戏中"挑战者"无必胜策略，
⟺ 一族大小 ≤ k 的子公式保持"可扩展可满足性"。**操作推论（我们引用的形式）**：
对 CNF 公式 F，w(F ⊢ ⊥) ≥ tw(primal 图)（更精确地：≥ primal/关联超图的树宽减常数）。
- 用途：树宽是宽度的**下界**；我们 E1 的 tw_controlled 族给出宽度的**上界**（tw ≤ k
  ⇒ 存在宽度 O(k) 的反驳，标准动态规划）。

### 2. 宽度-规模关系（Ben-Sasson–Wigderson）
对 k-CNF F（初始宽度 w₀ = k），若存在宽度 w 的反驳，则存在规模
**S ≥ exp(Ω((w − w₀)²/n))** 的所有反驳的规模下界（即最短反驳也 ≥ 此界）。
- **宽度屏障（width barrier）**：把阈值 w* = √(n·log n) 代入：w = c√n ⇒
  exp(Ω(c²)) = 常数（无约束力）；w = n^0.6 ⇒ exp(Ω(n^0.2)) 超多项式；
  w = Θ(n) ⇒ exp(Ω(n)) 指数。即**只有宽度超过 √(n log n) 量级才强制超多项式消解规模**。
- 硬方向应用：随机 3-SAT 阈值区 w(F ⊢ ⊥) = Θ(n) w.h.p. ⇒ 消解规模指数 ⇒ CDCL 难
  （与 E2 money plot 的相变峰一致）。
- 易方向应用：tw ≤ k ⇒ 宽度 ≤ O(k) ⇒ 只要 k = O(√n) 就**不**触发宽度屏障
  ⇒ 存在多项式规模反驳。

### 3. CDCL 与消解的模拟关系（BKSS 2003 + AFT 2011）
- BKSS：带重启的 CDCL 可多项式模拟一般消解（学习子句序列即消导出）。
- AFT：更细的对应——"重启 + ≤ n 决策层 + 1UIP"的 CDCL 运行精确对应**有界宽度消解**；
  反过来，宽度 w 的消解反驳可被 w 决策层的 CDCL 找到。
- **合并成完整易解链**：tw ≤ k ⇒ 宽度 O(k) ⇒ 多项式规模证明存在（B-W）⇒
  CDCL+重启多项式时间找到（BKSS）。**这正是我们 E1 unplanted 臂"全 k 平坦 ~10 冲突"
  的定理级解释**；planted 臂全零平台则由种植结构对 CDCL 的平凡性解释（见 PILOT_FINDINGS）。

### 4. 相关衰减与局部算法（Weitz STOC 2006；与 OGP 笔记互补）
- Weitz：度 ≤ Δ 的图上独立集计数，活动参数 λ < Δ−1 时自避走树上的相关指数衰减
  ⇒ 存在只用 O(log n) 半径局部信息的 FPTAS。这是"局部信息足够"的算法侧正面结果。
- 反面（OGP 笔记已详）：λ/耦合阈值之上、以及晶格类模型中 κ-stability 失败处，
  局部算法与长程相关冲突 ⇒ OGP 障碍。
- **与本项目的接口（谨慎表述）**：相关衰减决定"半径多大的局部观测足够做出全局正确
  判断"。我们的 r 是**子句采样的几何半径**（变量交互跨度），不是算法的读取半径；
  两者通过"局部算法适用域"间接相关：r 小 ⇒ 交互局部 ⇒ 实例的行为像低维几何模型
  ⇒ 小 UNSAT 子公式可发现（Bläsius Thm 7.12）；r 大 ⇒ 交互跨度增长 ⇒ 进入平均场/
  全连接体制 ⇒ 阈值区宽度的经典随机公式行为。**切勿在报告中写成 CDCL 是局部算法。**

## 二、与 r 的定量映射（E3a 主扫描的解读骨架，写报告时展开）
1. **r → 有效维数 → 全局树宽**：2D 环面 tw = Θ(√n) 对一切 r 成立（宿主拓扑固定），
   所以 AD 下界链对所有 r 一样"松"；变化的量是**局部结构**：r-球内子句在 VIG 上
   形成直径 ~r 的团簇，簇间稀疏耦合。r 增大 ⇒ 簇内稠密化 + 簇间耦合变强 ⇒
   可反驳"局部证据"（小 UNAT 子公式）从"r-球内可发现"退化为需要全局信息。
2. **为何 2D 几何带是甜点区**：宽度 ~√n < 屏障 √(n log n)（B-W 不咬），
   同时几何性给出小 UNAT 子公式（Bläsius 易证）——两个理论工具在此一致预言
   "CDCL 快"，而经典随机公式（r=∞）宽度 Θ(n) 预言"CDCL 慢"。α_c(r) 非单调
   （R3 发现：r=0.15 处 4.15 < r=0.06 处 3.0）的候选解释之一：
   中等 r 已破坏"小簇独立可反驳"但尚未达到全耦合。
3. **E3a 预测（预注册内不含，作为分析框架而非假设）**：若 H2 成立（r 有因果效应），
   效应应随 Δ 增大而放大（相变区附近宽度/证据结构最敏感）；
   若只看到 r×Δ 交互而无 r 主效应，则"局部性通过改变相变位置而非平移难度曲线起作用"。

## 三、CDCL 理论模型 vs 实际 CDCL 的鸿沟（效度威胁，报告必写）
- 理论结果针对"重启 + n 决策层"的抽象 CDCL；实际求解器（CaDiCaL/Glucose）的
  VSIDS、重启调度、子句删除、预处理都在模型之外。宽度屏障是**下界工具**：
  它证明"某些实例上不存在短证明"，但**不能证明实际 CDCL 一定慢**（实际求解器
  可能绕过消解度量）——我们的难度测量是实证冲突数，理论链只做解释不做保证。
- 反过来，低 tw ⇒ 快的链依赖 BKSS 模拟定理的"找到"方向，对实际启发式同样无保证；
  E1 的平坦结果是其**实证印证**而非推论。
