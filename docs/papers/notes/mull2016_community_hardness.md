# 精读笔记：Mull, Fremont & Seshia — 社区结构不能解释 CDCL（H1 的理论警示 + H2 的实验先例）

## 来源与核验状态
- Nathan Mull, Daniel J. Fremont, Sanjit A. Seshia, *On the Hardness of SAT with Community
  Structure*, SAT 2016, Springer LNCS 9710（doi:10.1007/978-3-319-40970-2_10）。
  全文经 arXiv:1602.08620 的 ar5iv HTML 版逐节阅读（ar5iv 渠道 2026-09-09 验证可用）。
- 三个关键事实：(a) 这篇论文直接针对"社区结构解释 CDCL 成功"这一假说做理论否定；
  (b) 其实验部分给出了"社区规模而非公式规模主导难度"的直接证据；(c) 其平均案例
  结果适用于 Giráldez-Cru & Levy 的 community attachment（CA）模型——我们
  giraldez-cru-2017-locality.md 笔记的姊妹篇（CA 是 2015 modularity 生成器，
  IJCAI 2017 论文是其局部性推广）。

## 一、最坏情形：PCM 类度量全部无鉴定力（Thm 3.1 + 3.2）
- **PCM（polynomial clique metric）定义**：图度量 m 是 PCM，若 ∀ε>0 存在多项式
  可计算的 c(n)，使得 m(K_n^{c(n)}) ≥ 1−ε——即"多项式个互不相交的团"就能达到
  近满分。直觉：团簇是理想社区，模ularity 类度量必然给 K_n 拼盘高分。
- **Thm 3.1**：modularity 是 PCM（Q(K^c) ≥ 1−1/c）；附录 A 证明 silhouette index、
  conductance、coverage、performance 全是 PCM（且更平凡：c=1 即可）。
- **Thm 3.2**：对任意 PCM m 与任意 ε>0，{φ : m(VIG(φ)) ≥ 1−ε} 仍是 NP-hard。
  归约：把任意公式 φ 用子句 x∨y∨z 填充（VIG 变成 K_n，等可满足——令 x=true 即可），
  再取 c(n) 个变名拷贝。**结论：任何模ularity 型度量都不可能成为易解性证书（除非 P=NP）**。
- 引用 Ganian & Szeider (SAT 2015)：高模ularity SAT 仍 NP-hard（本文是其推广 +
  平均案例升级）；h-modularity 是唯一正结果，但与 modularity 定义差异大、
  无证据表明工业实例上小、且其算法与 CDCL 完全不同。

## 二、平均案例：CA 模型少社区时 CDCL 指数难（Thm 4.2）
- CA 模型 F_k(n,m,c,p)（Giráldez-Cru & Levy IJCAI 2015）：变量划成 c 个社区，
  每子句以概率 p 取社区内均匀子句，否则取"桥子句"（变量跨 k 个社区）。
  期望 modularity ≥ p − 1/c。经验上：高模ularity CA 实例 CDCL 比 look-ahead 快、
  低模ularity 反之——这正是它被当作"伪工业"模型的原因。
- **Thm 4.2**：m=O(n)、c=O(n^α)、α<1/10 时，不可满足实例 w.h.p. 需要长度
  2^{Ω(n^λ)} 的消解反驳 ⇒ CDCL w.h.p. 指数时间。
- 证明骨架（对我们有价值的是方法而非数字）：
  1. CA 分布 ≡ 均匀随机 k-SAT F_k(n, (1+ε)c^{k-1}m) 的"按社区比例子采样"（Alg 1）；
  2. 稀疏性（n'-sparse、(n',n'',y)-sparse）是**子公式继承**性质；
  3. Beame–Pitassi 1996 简化消解下界经 L6–L8 移植过来 ⇒ 宽度 Ω(εn') ⇒
     规模 2^{Ω(n^λ)}。
  - 技术含义：**"随机公式的难度证明可以搬运到结构化伪工业模型"**——靠的是
    子采样等价 + 继承性质。这对我们 E3a 的意义：geo_random 族若被质疑"太随机、
    不像工业"，其难度结论可援引此路线。
- **p<1 非平凡性**（Discussion 明确）：p=1 时实例 = c 个独立规模 n/c ≥ Ω(n^{9/10})
  的随机问题，由旧结果直接指数——平凡。p<1 时桥子句原则上可能"帮助"传播、
  提前暴露矛盾；本文证明在 c 小时这 w.h.p. 不发生。**桥子句的"胶水"作用不自动
  让实例变易——与我们 E3a 中"跨簇耦合随 r 增大"的设计关注点同构。**

## 三、实验：社区规模（不是公式规模）主导运行时间（Fig 1，H2 最重要的实验先例）
- 设置：F_3(n, 5n, 5n^α, 0.9)，α∈{0.1,0.2,0.3,0.4}，MiniSat 2.2.0，每档 10 实例。
  所有实例期望 modularity ≥ 0.8（高模ularity 区）。
- 结果：运行时间随**社区规模**（=n^{1−α}/5）指数爆炸，且四条 α 曲线几乎重合：
  - 社区规模 ~270 时：α=0.1 实例 3,000 变量，α=0.4 实例 165,000 变量
    （**相差 55 倍**），运行时间只差 **~3 倍**。
- 作者结论："community size is a much more important factor in determining
  runtime than the total formula size"。
- **与 H2 的关系（写论文的承重段落）**：这已经是"局部工作集规模决定难度"的
  观察性证据——但它是**观察性**的（社区规模与变量数、社区数、α 全部纠缠在
  一个参数化族里，没有控制混杂）。我们的 E3a 用 r-球采样在固定 n、α、
  度分布下直接干预"交互跨度"，正是把这一现象升级为**因果**主张的实验。
  报告中必须引用并明确这个"观察→干预"的递进关系。

## 四、作者自列的边界（ Discussion，我们引用时不可省略）
1. 理论只排除"高模ularity ⇒ 多项式平均"，**不排除**把 2^{n^{1/2}} 降到
   2^{n^{1/4}}——对小 n 这就是可行与不可行的差别。即社区结构可能是
   "指数减法器"而非"多项式化器"。→ 我们 H1 的"解释方差"主张要与此对齐：
   结构度量做难度**排序**（预测器）与做易解性**证书**是两回事，PCM 结果
   只封死了后者。
2. c 的下界缺口：证明限于 c=O(n^{1/10})；而 c=Θ(n/log n) 时结果**必然失败**
   （c→∞ 时 w.h.p. 某个社区自身不可满足 ⇒ 存在多项式反驳）。作者的小实验
   （α 到 0.4）显示指数爆炸在更大 c 下仍在，但"很多小社区"体制是
   理论上可能的易解区——这恰是我们 r 干预扫描要覆盖的体制之一
   （r 小 ⇒ 有效"社区"多而小）。
3. VIG 丢弃了全部布尔信息（极性、子句内容）——作者明言值得找保留更多信息
   的图编码。**这正面支持我们"拓扑×内容正交分解"的动机**：社区度量只在
   VIG（拓扑通道）上打转，我们的 2×2 设计同时操纵两个通道。

## 五、CDCL-消解下界桥（补 width_decay_barrier.md）
- 本文 §2.2/§4.5 明确引用的桥是 Beame, Kautz, Sabharwal (IJCAI 2003)：
  CDCL（任意分支/学习/重启启发式）在不可满足实例上的运行时间（多项式因子内）
  ≥ 最短消解反驳长度。与 width_decay 笔记里 AFT 2011 的有界宽度对应互补：
  下界论证用 BKSS 桥即可，宽度刻画用于上界/易解方向。
- 另注：预处理（BCE 等不加子句的技术）不破坏此下界——与我们 metrics 在
  预处理前计算的选择相容（但见 Zulkoski 笔记：Zulkoski 在预处理**后**算度量，
  两口径差异是他们与 Newsham R² 分歧的来源之一；我们 E5 双口径报告的理由再加一条）。
