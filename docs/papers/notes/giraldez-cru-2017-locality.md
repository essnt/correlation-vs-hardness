**认知修正/确认**：该论文确为 SAT 公式**局部性**生成器论文（而非 locality 理论分析）：提出 Popularity-Similarity（PS）随机 SAT 模型，是**首个同时生成幂律变量出现分布（scale-free/popularity）与局部性/社区结构（similarity）的随机 SAT 模型**，并用温度参数 T 连续调节局部性强弱。

## 2. 核心研究问题（写给非计算理论背景的读者）

工业 SAT 实例有两个显著结构特征：变量出现次数服从幂律分布（少数"热门"变量出现极多，指数 δ∈[2,3]，Ansótegui et al. 2009a）和社区/局部结构（变量被子句"抱团"连接）。但已有的随机生成器只能二者取一：Scale-free 模型只有幂律没有局部性，modularity/Community Attachment 模型只有社区没有幂律。要研究"结构如何影响求解难度"，必须有一个能**独立控制每个结构维度**的生成器——本文用复杂网络中的"popular vs similar"两类连边驱动力，造出第一个同时具备两种结构、且可通过温度旋钮在"强局部"到"纯随机"之间连续滑动的随机 SAT 模型。

## 3. 方法概要

- **PS 模型定义（Section 2，Def. 1，Eq. 1）**：给 n 个变量、m 个子句各分配一个 [0,2π] 上的随机角度 θ_i、θ'_j（角度即"相似度"几何嵌入——同一圆环上角度近 = 相似/近邻）。二部图每条可能的变量-子句边 i↔j 以 Fermi-Dirac 型概率被选中：
  P(i↔j) = 1/(1 + (i^β · j^β' · θ_ij / R)^{1/T})，
  其中 i、j 为变量/子句编号（小编号 = 更热门），β 控制变量幂律指数、β' 控制子句长度幂律指数，θ_ij 为角度圆距离（**局部性/相似度项**），T 为温度，R 为归一化常数（保证期望边数 = k·m；T≤1 有解析近似式 R ≈ [sin(Tπ)/T · (1-β)(1-β') / ((n^{1-β}-1)(m^{1-β'}-1)k m)]，T>1 用 Newton–Raphson 迭代，4–5 次收敛到 ±0.1）。再对每条边以 1/2 概率赋正/负文字。
- **简化模型（Section 2.3，Eq. 3）**：P(i↔j) = min{1, R/(i^β j^β' θ_ij)^{1/T}}，把 R 变成近乎普通的归一化常数，迭代 2–3 步收敛。
- **关键旋钮的语义（Section 4 开头）**：
  - T→0：完全按"能量"（popularity + similarity）挑边；T→∞：所有边等概率 → **退化为经典 Erdős–Rényi 随机 k-CNF**。所以 **T 就是"局部性强度"的连续旋钮，T 越小局部性越强**。
  - β→0：无幂律；β→1：强幂律（δ = 1+1/β，Lemma 2 给出证明；子句长度指数 δ' = 1+1/β'）。
- **变长子句处理（Section 3）**：纯变长子句模型小子句泛滥、公式平凡 UNSAT、无尖锐相变；修法是每子句先放 K 个"相似度-only"分布（去掉 j^β' 项）挑出的文字，再加 k·m 个按完整分布抽取的文字（避免子句内重复变量），平均子句长 K+k。
- **实验设置（Section 4）**：固定 β'=0、K=3、k=0（纯 3-CNF）、**m/n = 4.25 固定**，n=5000（高温时降为 n=300，否则随机实例无人能解）。求解器：Minisat（VSIDS 决策轨迹分析）、Glucose（CDCL 代表）vs March（look-ahead，经典随机实例强手）。

## 4. 主要结果（保留关键数字）

- **首个同时具有 scale-free + community/locality + 变长子句的随机 SAT 模型**（Section 2、6），且证明生成实例的变量出现次数服从幂律 P(k) ~ k^{-δ}，δ = 1+1/β（**Lemma 2**，小 T 时成立）。
- **变长子句模型本身不可用（Section 3，Fig. 1）**：n=10⁴、最大熵变长子句模型的 SAT/UNSAT 相变带很宽且随 k 变化，无尖锐阈值；n=10⁵ 时几乎整个扫描区间全为平凡 UNSAT；虽最难点仍在相变区，但对现代求解器全都平凡可解 → 必须强制最小子句长度 K。
- **VSIDS 同时利用 popularity 与 similarity（Section 4，Fig. 2）**：对 n=5000 的 PS 公式画 Minisat 前 3 万次冲突内的决策变量轨迹——
  - 高 popularity（β=0.8, T=1.50，按热门度排序变量）：决策集中在低编号（热门）变量，印证 Ansótegui et al. 2009a；
  - 高 similarity（β=0.1, T=0.75，按角度排序变量）：决策**集中聚集在角度空间的某个局部区域**，且随搜索推进区域会漂移——直接可视化"求解器在局部邻域内搜索"；
  - 高温（T=100）：决策在全部变量上均匀散开，行为等同经典随机 CNF。
- **学习子句统计（Section 4）**：popularity 公式平均学习子句长 **18.2** 文字、冲突率 **584 conf/s**；similarity 公式 **20.3** 文字、**510 conf/s**；高温公式 **120.6** 文字、**154 conf/s**（每次 restart 后要大量决策才能找到冲突）。局部性使冲突更快出现、且冲突涉及的变量更少。
- **局部性–难度关系是非单调且依赖求解器类型的（Section 4，Fig. 3）**：Glucose vs March 散点，T 从 1.40 扫到 20——
  - T=1.40（强局部性）：所有公式秒解，两求解器都易；
  - T=1.45→1.50：公式变难，**Glucose（CDCL）明显优于 March**；
  - T=1.55：**两者都全败**（最难区间）；
  - T=5–20：公式对 March 变回容易（经典随机机制接管），CDCL 无优势。
  即：在固定的 n=5000、m/n=4.25 下，难度随 T 呈"先升后（对专用求解器）降"的峰状，CDCL 的优势窗口恰在中等局部性区段。
- **相变现象存在（Section 6）**：PS 模型保有一个 SAT–UNSAT 相变，使其适合造 50% 可满足的竞赛级实例。

## 5. 与我们项目的关系

我们研究：**SAT 实例变量交互的局部性（半径参数 r）如何因果地决定求解难度**。

- **对 H2（匹配密度后，局部性半径对难度的因果效应）——这是与本文最直接的接口，PS 模型几乎就是我们 H2 需要的实验仪器**：(a) 它把"局部性"做成连续旋钮 T，且 T 与密度（m/n=4.25）、与幂律异质性（β）**可独立设定**——正是我们"匹配密度后识别局部性因果效应"所需的正交控制；(b) Fig. 3 已经是一张"固定密度下，局部性参数 → 难度"的剂量响应曲线，且给出关键定性结论：**难度对局部性是非单调的**（强局部易 → 中等局部最难 → 弱局部对专用求解器又变易），并与求解器类型交互。这直接挑战任何"局部性单调地决定难度"的简单 H2 版本：我们的 r-难度曲线应预期非单调、并按求解器（CDCL vs 其他范式）分层；我们的"半径 r"对应本文的"角度阈值邻域"，可把 T（或等价的期望邻域半径）映射到 r 上做定量对比。
- **对 H1（结构指标解释难度）——提供机制解释与佐证**：Fig. 2 显示 CDCL 的分支启发式确实在利用局部性（决策聚集在角度局部区域），学习子句在局部性公式中更短（18–20 vs 120.6 文字）、冲突率更高（510–584 vs 154 conf/s）——即局部性通过"让冲突更快、让蕴含更局部"这一机制降低难度。这为 H1 中"结构指标为何与难度相关"提供候选中介变量（学习子句长度/冲突局部性），我们可以在 M2 中把"学习子句平均长度"作为中介变量加入结构指标-难度回归。
- **对 H3（LLM 启发式成功率随局部性变化）——提供可迁移的实验范式与预期**：Fig. 2 的"决策轨迹可视化"方法可直接搬到我们的 LLM 启发式上（检验 LLM 的变量选择是否也聚集在局部邻域、是否也偏向"热门"变量）；Fig. 3 的结论预示 H3 的结果形态：LLM 启发式若像 CDCL 一样依赖局部信息，其成功率应在强/中局部性区段高、在近随机区段崩塌（此时任何启发式都退化为猜）。注意本文对比的是两个经典求解器而非学习型启发式，"LLM 能否像 VSIDS 一样读出局部性"在本文中是开放问题。
- **方法学资产**：PS 模型（Eq. 1/Eq. 3）可作为我们 r-参数化生成器的对照生成器：它把局部性定义在**度量几何**（圆环角度）上，天然给出"两变量何时近"的全序，便于与我们基于 VIG 邻域半径 r 的定义做互证（geometric locality vs graph-radius locality）。
