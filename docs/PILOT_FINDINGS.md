# M1 Pilot 校准记录

状态：M1 pilot 完成（R1–R3b）｜ 更新：2026-09-09

## Round 1（E3a 第 1 版 + 全套基础设施冒烟）

**基础设施判定：全部达标**
- 生成器四族产出合法 3-CNF；σ-满足性 100%；E3b 交换链度序列**精确保持**、
  拒绝率 3.9%（远低于 30% 警戒线，MCMC 混合性无忧）。
- 度分布跨 r 锁死验证：n=800 时均值 12.00→12.08（<1% 漂移）。
- 树宽双界：修复两个 bug 后对 k-树真值验证通过（k=8→[8,9]），τ(lb,ub)=0.828≥0.8
  门槛达标；min-fill numpy 重写后 70s→1s/实例。
- r=1.5 锚点与独立随机 3-SAT 结构指标重合（tw 270≈272、模块度 0.196≈0.197）。
- 求解器封装：正常/删失双路径验证；`accum_stats` 提供冲突/决策/传播数。
- σ-冗余度跨 r 漂移 0.065（<0.1 门槛）。

**科学判定：难度载体缺失**——α=4.3 的 uniform-7 planted 公式在 CDCL 下全部
0 冲突（121/121）。原因确认：普通种植 3-SAT 在种植阈值以下对现代 CDCL 平凡易解
（这正是 Jia-Moore-Strain 2005 发明诱骗隐藏的动机；也是"quiet planting"直觉的
印证）。第一版 r 扫描的难度曲线是平的零线。

**顺带发现**：planted 实例的易解性对 r 完全不敏感——局部性无法救种植公式。
这本身是个可报告的观察（SAT 侧局部性失效，UNSAT 侧局部性主导）。

## Round 2（难度载体扫描）

- **"JMS 诱骗隐藏"勘误（2026-09-09，论文精读后修正，见 docs/papers/notes/jia2005_hiding.md）**：
  我们 pilot 实现的 σ/β 双赋值构造**不是** Jia-Moore-Strain 原文的 q-hidden——原文
  只有一个隐藏赋值 A，逐子句按 q^t 加权在 A-满足极性模式中采样（q=1 最易端，
  q<q*≈0.618 才是 deceptive 区），**没有 decoy 赋值也没有 flip 概率**；且我们的
  "deceptive" 边际吸引方向与原文机制相反。因此 R2 的 0 冲突结果只证明"我们的自创
  变体平凡"，**canonical q-hidden（paper-q∈[0.2, 0.618]）对现代 CDCL 从未测试**——
  任何"JMS 对现代求解器平凡"的表述作废。附带记号警告：JMS 论文的 r 是
  clauses/variables 比，与本项目的局部性半径 r 完全不同，后续实验严防静默混用。
- 双种植 UNSAT（v1）：blob 变量在自由位置不受约束 → 存在第三组解，全 SAT。
  已知修复方向（高 α 进入挫折区）但优先级降低——见 geo_random 的强信号。
- **geo_random（非种植几何族，Bläsius 体制）**：固定 α=5.0 的 UNSAT 区，
  冲突数 r=0.08→0（传播即时反驳）→ r=1.5→2.3×10^6。**六个数量级的难度摆动，
  纯由局部性驱动**。与 Bläsius et al. RSA 2023 的"局部性 ⇒ 小不可满足子公式"
  定理形成直接的经验对应。

**混杂识别**：α_c(r) 随 r 移动（粗扫：α_c(0.08)≈3.2, α_c(0.3)≈4.7, α_c(1.5)≈4.4），
固定 α 比较混入"距阈值距离"。Round 3 精测 α_c(r)，正式实验改用**匹配超临界密度
Δ = α − α_c(r)** 设计。

## Round 3（α_c(r) 精测）——完成

SAT 率 × α 矩阵（8 seeds/格，n=400，冲突预算 10⁶ 截断）：

- **α_c(r) 强非单调**：r=1.5→4.20（与随机 3-SAT 理论阈值 4.267 吻合，锚点二次验证）；
  r=0.11→3.85；r=0.08→3.25；r=0.06→3.00。局部性越强，相变越早——局部簇提前矛盾。
- **预算截断（=难格）只出现在 r≥0.3**：r≤0.11 即使 α=7.0 也零截断（平凡可解）。
  截断峰位置随 r 移动：r=0.3 峰在 α≈4.4，r≥0.5 峰在 α≈4.6。
- 深 UNSAT（α≥5.5）在所有 r 下都易解——经典的 easy-hard-easy 沿 α 轮廓。

**方法论事故与修复（重要工程记录）**：第一版 R3 用线程+`interrupt()` 做墙钟超时，
在硬实例上 CadicaL 不检查中断标志 → 主线程 `accum_stats()` 与仍在运行的 C++ 求解
死锁，16 worker 全部 100% CPU 空转 18 分钟零产出。改用**冲突预算截断**
（`conf_budget=10⁶`，CaDiCaL 每次冲突检查预算）后零挂起：finisher 报告精确冲突数，
预算耗尽者作为在 B 处的行政删失——与预注册的 Tobit/KM 语义严格对齐。
墙钟中断方案废弃记录在案。

## Round 3b（匹配 Δ 预演）——完成，H2 预演信号成立（触发预注册冻结）

设计：r ∈ {0.06, 0.08, 0.15, 0.30, 1.5} × Δ ∈ {-0.2, +0.2, +0.6}（α = α_c(r)+Δ）
× 20 seeds = 300 作业，全指标记录（树宽中介用）。300/300 落库，零挂起。

中位 log10(冲突数+1)（删失按预算值 6.00 计；括号内为预算删失比例）：

| r \ Δ | −0.2 (SAT) | +0.2 (近阈) | +0.6 (深UNSAT) |
|---|---|---|---|
| 0.06 | 1.54 | 1.38 | 1.31 (0%) |
| 0.08 | 1.57 | 1.75 | 1.52 (0%) |
| 0.15 | 2.79 | 3.32 | 2.47 (0%) |
| 0.30 | 4.32 (5%) | ≥6.00 (100%) | 5.96 (40%) |
| 1.5  | 4.41 (0%) | ≥6.00 (100%) | ≥6.00 (100%) |

结论：
1. 匹配 Δ 后难度随 r 单调上升：Δ=+0.2 臂 r=0.06→1.5 跨度 ≥4.6 个数量级
   （中位 ~24 冲突 vs ≥10⁶；删失使高端为下界，真实差距只大不小）。
2. r≤0.08 时即使深入 UNSAT（Δ=+0.6）也平凡可解（中位 ~20–30 冲突，零删失）——
   "局部性 ⇒ 易解"在 UNSAT 侧成立的直接证据。
3. 中间 r 沿 Δ 的 easy-hard-easy 轮廓重现（r=0.15: 3.32 @ +0.2 vs 2.47 @ +0.6）。
4. 天然配对点：r=0.15 与 r=0.30 的 α_c 粗估同为 4.15，α=4.35 处两 r 直接同 α
   对比——难度差 ≥2.7 个数量级，单点最干净的"纯拓扑效应"证据。
5. 误差边界：R3b 的 α_c 用 R3 粗估（8 seeds、α 步长 0.25），Δ 有 ±0.1–0.15 估计
   误差；该误差无法解释 4.6 个数量级的跨度，但正式实验仍须 M2-S0 精测
   （见 HYPOTHESES 冻结记录第 6 条）。

→ 触发冻结条件，预注册升级为 HYPOTHESES v1.0-FROZEN。
